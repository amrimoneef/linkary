# 📡 خطة كاشف النقطة الذهبية — Linkary Signal Finder

## نظرة عامة

ميزة تفاعلية فريدة تحوّل هاتف المستخدم إلى **رادار ذكي** لتحديد أفضل مكان لوضع المودم في الوقت الفعلي.

> المستخدم يفتح شاشة "كاشف النقطة الذهبية" → يبدأ بالمشي حاملاً المودم → الهاتف ينبض كـ"كاشف معادن" يتسارع نبضه كلما اقترب من نقطة إشارة قوية → يكتشف المستخدم "النقطة الأسطورية" ويثبّت المودم!

## 📊 البيانات المتاحة حالياً

### مصادر البيانات الجاهزة (لا حاجة لـ API جديد):

| المؤشر | المصدر | الدور |
|---|---|---|
| **RSRP** (قوة الإشارة) | `EngineeringInfoEntity.rsrp` | وزن 30% |
| **SINR** (نقاء الإشارة) | `EngineeringInfoEntity.sinr` | وزن 50% (الأهم للسرعة) |
| **RSRQ** (جودة الإشارة) | `EngineeringInfoEntity.rsrq` | وزن 20% |

### الـ API المستخدم:
```
GET http://mobile.router/api.cgi?path=cm&method=query_eng_info&timeout=20
```

**البيانات تُجلب بالفعل كل 5 ثوانٍ** عبر `DashboardController._startPolling()` → `fetchEngineeringInfo()`.  
في ميزة الكاشف، سنزيد التردد إلى **كل ثانيتين** للحصول على استجابة فورية.

## 🛠️ الحزم المطلوبة (إضافة جديدة واحدة فقط)

```yaml
dependencies:
  vibration: ^2.0.0    # اهتزاز متقدم مع أنماط مخصصة (كاشف المعادن)
```

> **ملاحظة:** الرسم البياني الحي (EKG Graph) سيتم بناؤه بـ `CustomPainter` بدلاً من مكتبة خارجية، لأنه:
> 1. أداء أعلى (60 FPS مضمون)
> 2. تخصيص كامل لتأثير تخطيط القلب
> 3. لا حاجة لتبعية إضافية

## 🎯 الرؤية التنافسية

> **Linkary** سيكون أول تطبيق إدارة مودم MiFi يوفر نظام **رادار حي لتحديد أفضل موقع** مع اهتزاز ذكي ورسم بياني فوري.  
> التطبيقات المنافسة (NetSpot, WiFi Analyzer) تقيس WiFi فقط — نحن نقيس **إشارة البرج الخلوي مباشرةً** مما يعطي نتائج أدق بكثير.
