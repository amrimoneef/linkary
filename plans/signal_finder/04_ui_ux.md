# 🎨 تصميم الواجهة — UI/UX Design

## الفلسفة التصميمية

> شاشة تبدو وكأنها **رادار عسكري متقدم** يعمل في الظلام، مع لمسات من ألعاب الفيديو.  
> المستخدم يشعر أنه يحمل جهازاً من فيلم خيال علمي، وليس مجرد تطبيق.

### المبادئ:
1. **Dark-first**: الشاشة مصممة للوضع الليلي أساساً (مع دعم الفاتح)
2. **Minimal text, Maximum visuals**: الأرقام والرسوم تتحدث
3. **Alive UI**: كل شيء يتحرك — لا عناصر جامدة
4. **One-hand friendly**: كل شيء يمكن رؤيته بيد واحدة

## 🎯 المكونات بالتفصيل

### 1. 🔵 دائرة النسبة المركزية (Composite Score Gauge)

**الملف:** `composite_score_gauge.dart`

- دائرة كبيرة (280×280) في المنتصف
- **3 طبقات متحركة:**
  1. **حلقة خارجية** (Arc): تمتلئ بالتدريج حسب النسبة مع تأثير Gradient
  2. **الرقم المركزي**: نسبة كبيرة (74%) تتغير بـ `AnimatedSwitcher`
  3. **توهج خلفي** (Glow): وهج بلون التصنيف ينبض
- **اللون يتغير ديناميكياً:**
  - أحمر → برتقالي → أزرق → أخضر مع تغير النسبة
- **تنعيم**: `TweenAnimationBuilder` لتحريك الرقم بسلاسة (لا قفزات)
- **هالة نابضة**: تأثير Pulse خفيف حول الدائرة بلون التصنيف

```dart
// مثال مبسط للمفهوم:
TweenAnimationBuilder<double>(
  tween: Tween(begin: oldScore, end: newScore),
  duration: const Duration(milliseconds: 800),
  curve: Curves.easeOutCubic,
  builder: (context, value, child) {
    return CustomPaint(
      painter: _ScoreGaugePainter(
        score: value,
        color: _getColorForScore(value),
      ),
    );
  },
)
```

### 2. 🏅 شارة التصنيف (Signal Rank Badge)

**الملف:** `signal_rank_badge.dart`

- حاوية متحركة تظهر اسم التصنيف الحالي
- **تأثيرات عند تغيير التصنيف:**
  - `AnimatedContainer` لتغيير اللون بسلاسة
  - `ScaleTransition` عند الترقية (من Critical → Stable: تكبير لحظي)
  - نص عربي/إنجليزي (مثال: "🔵 نقطة جيدة — Stable")
- **تأثير خاص لـ Legendary:**
  - شارة ذهبية مع تأثير Shimmer (وميض ذهبي يجري على النص)
  - أيقونة 👑 إضافية

### 3. 💡 بطاقة النصيحة المتغيرة (Guidance Message Card)

**الملف:** `guidance_message_card.dart`

- بطاقة زجاجية (Glassmorphism) بخلفية شبه شفافة
- النص يتغير بـ `AnimatedSwitcher` مع تأثير FadeIn
- **النصوص حسب الحالة:**

| الحالة | الرسالة |
|---|---|
| Dead Zone + Declining | 💀 "ابتعد فوراً! هذه منطقة ميتة" |
| Dead Zone + Stable | 🔴 "هذا المكان سيء، جرّب غرفة أخرى" |
| Critical + Declining | ⚠️ "الإشارة تضعف... ارجع خطوة!" |
| Critical + Improving | 🟠 "تتحسن! استمر في هذا الاتجاه" |
| Critical + Stable | 🟠 "إشارة ضعيفة، جرّب بالقرب من نافذة" |
| Stable + Declining | 🔵 "كانت أفضل... ارجع قليلاً" |
| Stable + Improving | ✨ "ممتاز! أنت تقترب من النقطة الذهبية!" |
| Stable + Stable | 🔵 "مكان جيد! اضف 3 نقاط بالتقدم نحو النافذة" |
| Legendary + أي اتجاه | 🏆 "قف! أنت في النقطة الذهبية! ثبّت المودم هنا!" |
| Legendary + Best Score | 🎉 "مبروك! هذه أقوى نقطة اكتشفتها!" |

- **رسائل إضافية سياقية:**
  - بعد 30 ثانية بدون تحسن: "💡 نصيحة: اتجه نحو النوافذ أو الشرفة"
  - بعد دقيقة: "💡 جرّب الانتقال لغرفة أخرى"
  - عند SINR منخفض فقط: "📡 تشويش عالي، ابتعد عن الأجهزة الإلكترونية"
  - عند RSRQ منخفض فقط: "📡 تداخل أبراج، جرّب جهة أخرى من المبنى"

### 4. 📊 صف المؤشرات المصغّرة (Metrics Mini Row)

**الملف:** `metrics_mini_row.dart`

- 3 بطاقات صغيرة أفقية تعرض:
  - القيمة الخام (مثل `-88 dBm`)
  - النسبة المُطبّعة (مثل `80%`)
  - شريط صغير ملون يعكس الحالة
- **تصميم مضغوط:** كل بطاقة ~100px عرض
- **ألوان مستقلة:** كل مؤشر له لونه الخاص بناءً على حالته

### 5. 📈 الرسم البياني الحي — Live EKG Graph

**الملف:** `live_ekg_graph.dart`

**التصميم والملامح:**

- **الحجم:** عرض كامل الشاشة × 120px ارتفاع
- **الأسلوب:** يشبه تخطيط القلب (ECG/EKG)
- **البيانات:** آخر 15 نقطة = 30 ثانية (نقطة كل 2 ثانية)
- **التمرير:** يتحرك لليسار باستمرار (RTL للعربية) مع دخول نقاط جديدة
- **اللون:** يتغير تدريجياً حسب القيمة:
  - خط أحمر → برتقالي → أزرق → أخضر
- **تأثيرات بصرية:**
  - **توهج (Glow):** خط مزدوج: خط رفيع حاد + خط ممسوح (blur) يعطي تأثير النيون
  - **Gradient Fill:** تعبئة شفافة أسفل الخط
  - **نقطة نابضة:** في نهاية الخط (آخر قراءة) نقطة تنبض
  - **خطوط مرجعية أفقية:** خطوط منقطة عند 25%, 50%, 80% مع تسميات

```dart
class LiveEkgGraph extends StatefulWidget {
  final List<SignalPoint> points; // آخر 15 نقطة
  final double currentScore;
  
  // ...
}

class _LiveEkgGraphPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    // 1. رسم خطوط المرجع الأفقية (25%, 50%, 80%)
    // 2. رسم الخط المتوهج (Glow line - blurred)
    // 3. رسم الخط الأساسي (Sharp line)
    // 4. رسم التعبئة المتدرجة أسفل الخط
    // 5. رسم النقطة النابضة في النهاية
  }
}
```

**الخطوط المرجعية:**
- `y = 80%` — خط أخضر منقط: "🟢 أسطوري"
- `y = 50%` — خط أزرق منقط: "🔵 جيد"
- `y = 25%` — خط أحمر منقط: "🔴 حرج"

## ✨ التأثيرات المتحركة

### 1. دائرة النسبة:
- `TweenAnimationBuilder` على progress (800ms, easeOutCubic)
- توهج نابض على الحلقة (opacity pulse 1.5s)

### 2. شارة التصنيف:
- `AnimatedContainer` لتغيير اللون (500ms)
- `ScaleTransition` عند الترقية (bounce curve)
- `ShimmerEffect` على Legendary

### 3. النصيحة:
- `AnimatedSwitcher` مع `FadeTransition` (300ms)

### 4. الرسم البياني:
- خط سلس باستخدام Cubic Bezier curves
- نقطة نابضة بـ `AnimationController` (600ms repeat)
- تمرير أفقي ناعم

### 5. الخلفية:
- وهج محيطي (Ambient Glow) ينبض ببطء بلون التصنيف الحالي
- يتغير اللون بـ `AnimatedContainer` (1s)

## 📱 الاستجابة (Responsive)

- **الدائرة:** `LayoutBuilder` — تتكيف مع حجم الشاشة
- **الرسم البياني:** عرض كامل الشاشة دائماً
- **المؤشرات المصغّرة:** `Row` with `Expanded` — تتوزع بالتساوي
- **SafeArea:** محمية من notch و navigation bar
