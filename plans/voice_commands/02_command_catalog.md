# 📋 كتالوج الأوامر الصوتية — Voice Command Catalog

## نظرة عامة

كل أمر يتبع هذا الهيكل:

| الحقل | الوصف |
|---|---|
| **الفئة** | التصنيف العام (أجهزة، شبكة، أمان...) |
| **النية** | نوع العملية (استعلام / إجراء / تنقل) |
| **الأنماط** | الصيغ المختلفة التي يمكن أن يقولها المستخدم |
| **المعاملات** | البيانات المطلوبة (اسم جهاز، قيمة...) |
| **المتحكم** | الـ Controller الذي ينفذ الأمر |
| **التأكيد** | هل يحتاج تأكيد المستخدم؟ |
| **الاستجابة** | ما يقوله المساعد بعد التنفيذ |
