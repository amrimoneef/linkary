# 🎤 خطة الأوامر الصوتية العربية — Linkary Voice Assistant

## نظرة عامة

إضافة مساعد صوتي ذكي باللغة العربية للتحكم الكامل بالمودم صوتياً.  
المستخدم يضغط زر الميكروفون ويقول أمرًا مثل:

> "كم جهاز متصل؟" أو "أعد تشغيل المودم" أو "احظر جهاز أحمد"

فيقوم التطبيق بفهم الأمر → تنفيذه → الرد صوتياً بالنتيجة.

## 📊 الميزات المدعومة حالياً في التطبيق

بناءً على التحليل الشامل للمشروع، الأوامر الصوتية ستغطي **جميع** وظائف التطبيق:

| الميزة | Controller | العمليات المتاحة |
|---|---|---|
| لوحة التحكم | `DashboardController` | استعلام البطارية، الإشارة، السرعة، الاستهلاك |
| الأجهزة المتصلة | `ConnectedDevicesController` | عدد الأجهزة، قائمة الأجهزة، تسمية |
| التحكم الأبوي | `ParentalControlController` | تقييد جهاز، حذف قاعدة، تفعيل/تعطيل |
| فلتر MAC | `MacFilterController` | حظر جهاز، إزالة حظر، تغيير الوضع |
| تحديد السرعة | `SpeedLimitController` | تفعيل/تعطيل، تعيين سرعة لجهاز |
| إعدادات WiFi | `WifiSettingsController` | تغيير كلمة السر، تغيير اسم الشبكة |
| إعادة التشغيل | `AuthController` | reboot، logout |
| الرصيد | `BillController` | استعلام الرصيد والباقة |
| استهلاك البيانات | `DataUsageController` | كم استهلكت، معايرة |
| إعدادات المسؤول | `AdminSettingsController` | تعديل كلمة المرور، الجلسة |

## 🔧 الحزم المطلوبة

```yaml
dependencies:
  speech_to_text: ^7.0.0    # التعرف على الكلام (يدعم العربية)
  flutter_tts: ^4.2.0       # الرد الصوتي (Text-to-Speech)
```

**لا حاجة لخدمات سحابية** — كل شيء يعمل محلياً على الجهاز.

## 🎯 الرؤية التنافسية

> **Linkary** سيكون أول تطبيق إدارة مودم يوفر تحكماً صوتياً كاملاً باللغة العربية.  
> لا يوجد منافس يقدم هذه الميزة لأجهزة المودم المحمولة.
