# 📊 خطة تطوير مراقب التطبيقات — Linkary App Monitor
## الإصدار الاحترافي المنافس

## نظرة عامة

مراقب التطبيقات هو ميزة تتبع استهلاك البيانات لكل تطبيق عبر شبكة MiFi في الوقت الفعلي. الهدف: تحويله من أداة أساسية إلى **مراقب احترافي منافس** على مستوى تطبيقات مثل GlassWire و NetGuard.

> المستخدم يفتح مراقب التطبيقات → يرى لوحة تحكم فورية بالاستهلاك → يراقب السرعة اللحظية لكل تطبيق → يتلقى تنبيهات ذكية → يحلل أنماط الاستخدام عبر رسوم بيانية تفاعلية → يتحكم بالتطبيقات المستهلكة.

## 📊 الوضع الحالي (ملخص)

### ✅ ما يعمل حالياً:
- تتبع الاستهلاك عبر WiFi لكل تطبيق (Android NetworkStats API)
- حساب الفرق بين الجلسات (Delta Calculation)
- تخزين محلي للبيانات اليومية (SharedPreferences)
- كشف إعادة تشغيل المودم (Uptime Sync)
- فلاتر زمنية (جلسة، يوم، أسبوع، شهر)
- رسم بياني بسيط (Bar Chart)

### ❌ نقاط الضعف الحرجة:
- **معمارية مكسورة**: DI يتم يدوياً في `network_info_page.dart` بدلاً من `injection_container.dart`
- **شاشة واحدة مونوليثية**: 391 سطر بدون تقسيم إلى Widgets مستقلة
- **لا توجد تفاصيل للتطبيق**: نقرة على التطبيق لا تفعل شيئاً
- **لا توجد تنبيهات استهلاك**: لا يحذر المستخدم من الاستهلاك العالي
- **الـ UI بسيط جداً**: يفتقر للحيوية والتفاعلية مقارنة بباقي الشاشات
- **انتهاك أنماط الثيم**: يستخدم `Get.isDarkMode` مباشرةً (يجب `Theme.of(context)`)
- **لا توجد إمكانية التصدير أو المشاركة**
- **لا يوجد تصنيف ذكي** للتطبيقات (شبكات اجتماعية، ألعاب، نظام...)

## 🎯 الرؤية التنافسية

> **Linkary App Monitor** سيكون أول مراقب تطبيقات مخصص لأجهزة MiFi يقدم:
> 1. **تتبع ذكي** مرتبط بجلسة المودم الفعلية
> 2. **تنبيهات استباقية** عند الاستهلاك المفرط
> 3. **تحليل أنماط الاستخدام** بالذكاء الاصطناعي المحلي
> 4. **واجهة فضائية تفاعلية** مع رسوم بيانية حية
> 5. **تقارير قابلة للمشاركة** بتصميم احترافي

## 🛠️ التبعيات المطلوبة

```yaml
# موجود بالفعل:
dependencies:
  fl_chart: ^0.68.0          # الرسوم البيانية
  shared_preferences:        # التخزين المحلي
  network_info_plus: ^5.0.3  # كشف الشبكة
  iconsax:                   # الأيقونات

# مقترح إضافته:
  # لا حاجة لمكتبات جديدة - كل شيء يُبنى بالأدوات المتاحة
```

> **فلسفة Zero-Dependency**: كل الميزات الجديدة ستُبنى بـ Flutter الأصلية و CustomPainter بدون اعتماد على مكتبات خارجية إضافية. هذا يحقق أداء عالي وتحكم كامل.
