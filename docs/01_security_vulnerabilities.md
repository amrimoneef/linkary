## 1. كلمة مرور المودم تُرسل بتشفير MD5 ضعيف
| البند | التفاصيل |
|-------|----------|
| **الملف** | `auth_remote_data_source.dart` |
| **الخطورة** | 🔴 مرتفعة |
| **الوصف** | يتم تشفير كلمة المرور باستخدام `MD5(rand + password.toLowerCase())`. خوارزمية MD5 مكسورة تشفيرياً منذ سنوات، كما أن تحويل كلمة المرور إلى أحرف صغيرة `toLowerCase()` يُقلّص فضاء كلمة المرور ويُسهّل الهجمات. |
| **الملاحظة** | هذا السلوك مفروض من firmware المودم وليس خطأ المطور، لكن يجب توثيقه كمخاطرة أمنية معروفة. |
| **التوصية** | توثيق هذا القيد. إذا أمكن، استخدام HTTPS عبر شهادة ذاتية التوقيع عند التواصل مع المودم. |

## 3. عدم تخزين الجلسة بشكل آمن (Session Storage)
| البند | التفاصيل |
|-------|----------|
| **الملف** | `auth_controller.dart` |
| **الخطورة** | 🟠 متوسطة |
| **الوصف** | يتم تخزين `sessionId` فقط في ذاكرة التطبيق (`currentUser` في `AuthController`). لا يوجد تخزين مشفّر (مثل `flutter_secure_storage`). عند إغلاق التطبيق تضيع الجلسة، ولكن الأهم أنه لا توجد أي حماية ضد قراءة الذاكرة. |
| **التوصية** | استخدام `flutter_secure_storage` لتخزين بيانات الجلسة الحساسة. |

| البند | التفاصيل |
|-------|----------|
| **الملفات** | `auth_remote_data_source.dart` (سطر 38-39)، `auth_controller.dart` (سطر 52) |

| **الوصف** | يتم طباعة بيانات حساسة في الـ Console باستخدام `print()`: معرّف الجلسة (`sessionId`)، استجابات المودم الخام، ومعلومات التحدي (`rand`). في بيئة الإنتاج، هذه المعلومات قد تُكشف عبر أدوات تسجيل الأخطاء (logging tools). |
| **التوصية** | إزالة جميع عبارات `print()` أو استبدالها بنظام تسجيل (Logger) يُعطّل تلقائياً في وضع الإنتاج (`kReleaseMode`). |

## 7. عدم وجود آلية Timeout للطلبات
| البند | التفاصيل |
|-------|----------|
| **الملفات** | جميع ملفات `*_remote_data_source.dart` |
| **الخطورة** | 🟡 منخفضة |
| **الوصف** | استخدام `http.Client` بدون تحديد `timeout` على مستوى الـ Client. الـ `timeout=20` الموجود في URL هو خاص بـ API المودم وليس timeout للطلب نفسه. إذا توقف المودم عن الاستجابة، قد يتعلق التطبيق بشكل غير محدود. |
| **التوصية** | استخدام `client.post(...).timeout(Duration(seconds: 15))` أو تكوين الـ Client مع timeout افتراضي. |
