# مواصفات ميزة صندوق الاقتراحات والملاحظات (Smart Feedback & Suggestions Box)

## 1. نظرة عامة (Overview)
ميزة متكاملة تتيح لمستخدمي Linkary إرسال اقتراحاتهم وملاحظاتهم وبلاغات الأعطال والتقييمات مباشرة إلى خادم `https://sam4g.com/api/feedback/app-settings`، مع دعم الصمود الكامل أثناء انقطاع الإنترنت عبر طابور محلي ذكي (Smart Offline Queue) وتضمين تشخيص النظام والراوتر بشفافية.

---

## 2. التصنيفات المعتمدة (Categories)
1. 💡 **اقتراح ميزة جديدة** (`feature_request`): أفكار لتطوير وتوسيع وظائف التطبيق.
2. 🐛 **إبلاغ عن عطل أو مشكلة** (`bug_report`): مواجهة خلل أو سلوك غير متوقع.
3. ⭐ **تقييم ورأي عام** (`general_feedback`): انطباعات عامة وتجربة المستخدم.

*(تم إلغاء تصنيف "طلب دعم مودم جديد" بناءً على توجيه المستخدم).*

---

## 3. عقد البيانات والـ API (Data Contracts & Security)
* **نقطة النهاية**: `POST https://sam4g.com/api/feedback/app-settings`
* **نوع المحتوى**: `multipart/form-data`
* **الحقول المرسلة**:
  * `category`: (feature_request / bug_report / general_feedback)
  * `title`: عنوان مختصر
  * `description`: شرح تفصيلي
  * `contact_info`: بريد أو هاتف (اختياري)
  * `include_diagnostics`: (true/false)
  * `app_version`: إصدار التطبيق
  * `device_model`: طراز الهاتف
  * `os_version`: نظام التشغيل
  * `modem_model`: طراز الراوتر الحالي إن وُجد
  * `modem_firmware`: إصدار السوفتوير إن وُجد
  * `network_type`: نوع التغطية (4G/5G) إن وُجدت
  * `battery_level`: نسبة البطارية إن وُجدت
  * `attachment`: ملف لقطة شاشة مضغوط (اختياري)
* **الرؤوس الأمنية (Security Headers)**:
  * `User-Agent: Linkary-App/1.0.0`
  * `X-Timestamp`: توقيت الطلب بالثواني
  * `X-Request-Nonce`: معرّف UUID فريد لمنع Replay Attacks
  * `X-App-Signature`: هاش `HMAC-SHA256` ديناميكي
  * `Accept: application/json`

---

## 4. تدفق البيانات والطابور الذكي (Offline Queue Logic)
1. **التحقق**: التأكد من ملء العنوان (3+ أحرف) والوصف (10+ أحرف).
2. **الحفظ أولاً**: حفظ الاقتراح في `SharedPreferences` بحالة `pendingOffline`.
3. **محاولة الإرسال الفوري**: عبر `http.MultipartRequest` بمهلة 12 ثانية.
   * في حال النجاح (200 OK): تحديث الحالة إلى `sent`، وعرض رسالة نجاح، وتفريغ النموذج.
   * في حال الفشل (أوفلاين أو خطأ): إبقاء الحالة `pendingOffline`، وإشعار المستخدم بالحفظ مع المزامنة التلقائية.
4. **المزامنة التلقائية (Auto-Sync)**: محاولة إعادة الإرسال في الخلفية عند فتح الصفحة أو استعادة الاتصال بالإنترنت الخارجي.

## 5. واجهات وتجربة المستخدم (UI/UX)
* **شاشة كاملة فاخرة (`FeedbackPage`)**:
  * تبويب أول: **تقديم اقتراح جديد** (أزرار التصنيفات الثلاثية، الحقول، إرفاق الصورة مع معاينة وحذف، بطاقة تشخيص فني قابلة للطي، زر إرسال متوهج).
  * تبويب ثانٍ: **سجل المتابعة** (عرض الاقتراحات السابقة بحالاتها وتواريخها، مع زر إعادة الإرسال للاقتراحات المعلقة).
* **نقاط الوصول**:
  1. بطاقة قياسية متناسقة في شاشة الإعدادات (`AllSettingsPage`) باستخدام `_buildSettingCard(...)`.
  2. شاشة حول التطبيق (`AboutPage`).
  3. مفهرسة في البحث السريع الشامل (`QuickSearchPage`).

## 6. سجل القرارات (Decision Log)
* **قرار 1**: إرسال الاقتراحات إلى `https://sam4g.com/api/feedback/app-settings`.
* **قرار 2**: حماية الـ API بتوقيع `HMAC-SHA256` مع طابع زمني و Nonce فريد.
* **قرار 3**: اعتماد 3 تصنيفات فقط واستبعاد "طلب دعم مودم جديد".
* **قرار 4**: توحيد بطاقة فتح الشاشة في `AllSettingsPage` مع بقية بطاقات الإعدادات.
* **قرار 5**: اتباع معمارية Clean Architecture كاملة ومستقلة في `lib/features/feedback/`.
